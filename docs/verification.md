# Проверка реализации

## LangChain create_agent, 4 ноября 2026

Основной live-цикл переведён на `langchain.agents.create_agent` с `StructuredTool`, `ToolRuntime` и middleware приложения. Полный прогон: **48 passed**, 13 предупреждений зависимости LangSmith. Ruff и форматирование изменённых Python-файлов — без ошибок, JavaScript-тесты — **4 passed**. `uv lock --check --offline` подтверждает согласованность зависимостей.

Интеграционный тест с настоящими OpenAI SDK и локальным Qdrant, но тестовым HTTP-транспортом, проходит цикл `rag_search → publish_support_draft → ответ → review`. Отдельный тест нового графа проверяет `list_knowledge_documents`, изоляцию документов владельцев, предложение заявки без записи, перезапуск во время подтверждения, продолжение вложенного checkpoint, единственную запись после approve и отсутствие второй записи после reject в следующем ходе. Платные OpenAI-вызовы и реальный Qdrant Cloud в этом прогоне не проверялись.

## Предыдущая проверка

Дата: 29 октября 2026. Среда: Windows, Python 3.14.3, зависимости закреплены в uv.lock.

Итоговый прогон: **34 passed** (`pytest -q -p no:cacheprovider`). Запуск через run.ps1 проверен; сервер слушает 127.0.0.1:8000.

Проверено:

- API integration через FastAPI TestClient и настоящие временные SQLite/Qdrant stores.
- История/idempotency, memory approve/edit/reject, новый thread, restart во время waiting_approval.
- Версии памяти, HTTP 409 при конфликте, owner isolation истории, каскадное удаление версий и идемпотентное повторение memory mutation.
- Устаревшее approval не перезаписывает новый факт; отмена на границе interrupt и корректная история tools следующего хода.
- Восстановление после сохранения финального checkpoint до application commit: без повторной модели, дубликатов ответа и финального SSE event.
- Owner isolation для documents/runs/approvals/artifacts, Qdrant filters и canonical checks.
- Артефакты, отмена, budgets, SSE; live tool-calling/reviewer с fake ChatOpenAI и DLP.
- E2B adapter с fake provider: network off, timeout, cleanup. Deep callback: запрет nested task и общий budget.
- Негативные SSRF/path cases, IPv4 priority при DNS pinning.
- Реальный health endpoint: HTTP 200. Реальный web_fetch https://example.com: 175 символов, TLS verification через системный trust store включён.
- Ruff, JavaScript syntax, Markdown links, покрытие 66 слайдов и JSON Schema Draft 2020-12.

Не проверено: визуальный результат в браузере (browser access host недоступен), Docker build, платные LLM/embeddings/Tavily/E2B calls, cloud isolation на реальном аккаунте, production load/restore. Adapters и protocol tests не заменяют эти проверки.

Облачные ключи не использовались. Pytest запускался с разрешением на системную Temp. Python 3.14 выдаёт deprecation warnings внутри LangSmith; это не ошибки приложения.
